# Архитектура SDK

## Текущий результат

Корневой пакет `vector-trading-sdk-workspace` — приватный пакет общих инструментов.
Он содержит конфигурации форматирования, линтинга, проверки типов и Vitest;
распространяемый код SDK и тесты общих инструментов пока отсутствуют.
Команды и закрепления описаны в [руководстве разработчика](development.md).

В серверной рабочей копии подготовлены канонические схемы, проверенные примеры и
детерминированный экспорт STEP-02. Транспортная семантика описана в
[контрактах](contracts.md). Снимок появится в SDK после принятия серверного commit;
временный экспорт с `commit: null` не считается таким снимком.

pnpm обслуживает корневые JavaScript/TypeScript-инструменты. В `pnpm-workspace.yaml`
зарезервирован только каталог `typescript`; пакеты Python, Go и Rust будут использовать
свои нативные средства. Сейчас языковых каталогов нет.

## Зона ответственности

Источник публичной семантики — маршруты и анализаторы сервера
`Vector-Trading/vector-trading`. SDK отвечает за HTTP-транспорт и формирование JSON
сигналов; права доступа, торговые правила, очереди и биржевое исполнение принадлежат
серверу. REST использует ключ аккаунта, вебхук — ключ стратегии. Эти ключи не взаимозаменяемы.

Корневой пакет не зависит от внутренних серверных пакетов. Установка и текущие
проверки выполняются без соседней копии сервера, MongoDB, Redis и учётных данных.
